## Overview

Unity Platformer is a 2D platformer game built in Unity.

The project focuses on player movement, level progression, multiplayer functionality, and responsive platforming controls. Players move through levels, avoid hazards, interact with the environment, and work through platforming challenges.

The game is built as a capstone-style Unity project, with a focus on combining gameplay programming, level design, UI, and WebGL deployment.

---

## Features

### Multiplayer Support

The game includes multiplayer functionality for two-player gameplay.

- Two-player controls
- Shared level space
- Player-specific input handling
- Tied together mechanic

### UI and Menus

The game includes menu and interface systems to support the player experience.

- Main menu
- Level navigation
- Gameplay UI
- Player feedback

---

## Controls

| Action | Player 1 |
|---|---|
| Move Left | A |
| Move Right | D |
| Jump | W / Space |

| Action | Player 2 |
|---|---|
| Move Left | Left Arrow |
| Move Right | Right Arrow |
| Jump | Up Arrow / Keypad Input |

> With more options being added.
